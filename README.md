# HR Analytics Dashboard | Tableau Project

Developed an interactive HR Analytics dashboard in Tableau to monitor workforce performance, analyze attrition trends, and identify high-risk employee segments.

- Objective

To convert raw HR data into meaningful insights that support strategic workforce planning and retention strategies.

- Solution Approach 

1 ) Designed KPI section for executive summary.

2 ) Created department-wise attrition visualization.

3 ) Analyzed age-group distribution to identify workforce concentration.

4 ) Evaluated gender-based and education-based attrition trends.

5 ) Included job satisfaction heatmap by job role.

- Key Metrics

1 ) 1,470 Total Employees

2) 237 Attrition Count

3) 16.12% Attrition Rate

4) 1,233 Active Employees

5 ) Avg Age: 37 Years

- Key Insights

1 ) Sales department shows highest attrition (56% of total exits).

2 ) Age group 25–34 has the highest attrition rate (18.14%).

3 ) Male attrition (150) is higher than female (87).

4 ) Life Sciences and Medical education backgrounds show higher exits.

5 ) Attrition is slightly above industry benchmark (10–12%).

 - Business Recommendations

1 ) Implement targeted retention programs for Sales department.

2 ) Provide career growth and promotion pathways for 25–34 age group.

3 ) Improve workload management and job-role alignment.

4 ) Strengthen engagement programs for high-risk segments.

 - Skills Demonstrated

1 ) Data Cleaning & Preparation

2 ) Dashboard Design & Storytelling

3 ) KPI Development

4 ) Workforce Analytics

5 ) Business Insight Generation

This project demonstrates strong analytical thinking and business problem-solving using Tableau.
